# SNPSU Marketing Presentation

This project was created for the **Marketing Stardom** competition conducted at **SNPSU**.

In this competition, teams had to invent a **fictional product** and present a marketing strategy to judges.

Our team created a concept product called **Snoozent – Pocket Awakener**, a fictional spray designed to help people stay awake during important moments like exams, study sessions, or late-night work.

Instead of using a traditional PowerPoint presentation, I built a **responsive website presentation** to showcase the product concept, marketing strategy, and promotional material.

## Features

* Interactive slide-style presentation website
* Dynamic content rendering using JavaScript
* Responsive layout for mobile and desktop
* Keyboard navigation between sections
* Poster and promotional video integration
* Modal interaction for product purchase (conceptual)

⚠️ Note
Snoozent is a **fictional product created purely for a college marketing competition** and is not a real commercial product.
